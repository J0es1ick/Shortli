# Frontend Shortli

Интерфейс построен на React, TypeScript и Vite.

## Реализованные возможности интерфейса

- настройка цвета и логотипа QR-кода в реальном времени на стороне клиента;
- адаптивные окна настройки QR-кода и отправки ссылки с закрытием по клавише
  и клику на фон;
- обновлённая история ссылок с копированием, отправкой, пагинацией и защищённым
  удалением;
- подтверждение выхода из учётной записи;
- адаптивная светлая и тёмная визуальная система;
- интерактивный сетевой фон, реагирующий на указатель и сенсорный ввод;
- автоматический выбор русской или английской локализации с анимированным
  ручным переключателем;
- необязательный пользовательский псевдоним короткой ссылки с серверной
  проверкой и обработкой конфликтов;
- срок действия, приостановка, возобновление и защищённое удаление отдельных
  ссылок;
- доступная только владельцу аналитика переходов по дням, устройствам,
  браузерам, операционным системам, источникам и странам;
- неизменяемый адрес назначения и защищённые хеши посетителей;
- кешированные перенаправления с асинхронной атомарной записью переходов;
- версионируемый публичный API с отзывными ключами, которые полностью
  показываются только один раз.

## Разработка

Установите зависимости и запустите frontend из корня репозитория:

```bash
npm --prefix frontend install
npm --prefix frontend run dev
```

API использует PostgreSQL из `compose.yaml`. Запускайте его из каталога
команды, чтобы существующий загрузчик конфигурации нашёл `backend/.env`:

```bash
docker compose up -d postgres
cd backend/cmd/shortliService
go run .
```

Сервер разработки работает на `http://localhost:43177` и проксирует `/api` на
`http://localhost:43178`. Высокие нестандартные порты выбраны намеренно, чтобы
проект мог работать одновременно с другими локальными сервисами. Если API
находится на другом origin, задайте `VITE_API_BASE_URL`.

## Публичный домен коротких ссылок

Укажите одинаковый origin коротких ссылок в обеих средах развёртывания:

```env
# backend/.env
PUBLIC_BASE_URL=https://go.example.com
FRONTEND_ORIGIN=https://example.com
COOKIE_SECURE=true
TRUSTED_PROXY_CIDRS=172.16.0.0/12
ANALYTICS_SALT=replace-with-a-long-random-secret

# frontend/.env.production
VITE_PUBLIC_BASE_URL=https://go.example.com
```

`PUBLIC_BASE_URL` определяет адрес ссылок и QR-кодов, возвращаемых API.
`VITE_PUBLIC_BASE_URL` используется интерфейсом как резервное значение, если
сервер не вернул готовый URL. Переменная `VITE_API_BASE_URL` не связана с
доменом коротких ссылок: она должна указывать непосредственно на API.
